# QQ Music plugin for MyGo Music

在 MyGo Music 的“设置 > 插件”中，通过右上角“+ > 从文件夹…”选择 `dist` 文件夹安装。已有旧版时，请先在插件的“…”菜单中移除旧版，再安装新版；播放器会保留原有插件设置。

直接连接 QQ 音乐，无需另行启动服务。未登录时可搜索歌曲、歌手、专辑和歌单，浏览精选歌单和排行榜、查看歌曲评论及 LRC 歌词，播放允许匿名播放的歌曲。

登录默认使用手机 QQ 扫码。在插件设置的“扫码登录方式”中输入“微信”并提交，再点击登录，可以使用微信扫码。登录后可请求个人歌单、喜欢的歌曲、收藏专辑和私人电台，也可编辑自己的普通歌单、喜欢歌曲和收藏专辑。播放会根据账号权限请求标准、高音质或无损音质，并在不可用时回退。**扫码确认后的登录和账号操作尚未使用真实账号端到端验证**，腾讯接口变化也可能使其失效。

登录凭据以明文保存在本机 MyGo Music 的插件数据中，并非系统密钥链。退出登录会删除本地凭据，但不会撤销 QQ 服务器上的登录会话。

支持 QQ 返回的逐字歌词和翻译，缺少逐字数据时回退至 LRC。目前不支持收听历史、关注歌手和发表评论。歌曲能否完整播放由 QQ 音乐的版权、账号及地区限制决定，插件不会绕过权限。

运行 `npm test` 执行离线协议测试；修改源码后运行 `npm run build` 重新生成安装目录。
